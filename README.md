The Drive Home — a two-part micro-confession for make.fun's "Unsent: The Micro-Confession Sprint" bounty. The program writes one unsent message, a To: line and the line itself, to `/output/entry.txt`.

Entry:

```text
To: Dad
I rehearse telling you I'm proud of you in the car on the way home, then I just ask if you've eaten yet.
```

## Run it

```sh
node main.ts
```
